# 錫呂瑪塔吉演講節錄・初階版（電子書閱讀版）

比照你提供的「生命的昇進」電子書閱讀器的介面與功能，套用到初階版166篇文章的內容上。
只有內容變，閱讀功能與介面完全比照原本設計。

## 這個版本 vs. 之前的簡易版

之前做的「初階版簡易App」（手風琴選單、綠色圖示）仍然可用，這個是**功能更完整的新版本**，兩者是不同的App（manifest名稱、快取代號都不同，可以同時裝在手機上）。

新版本多了這些原本沒有的功能：

- **封面頁 + 目錄**：19大類分組，每篇文章有編號
- **搜尋全書**：輸入關鍵字，結果會標示出現位置的前後文
- **劃重點（螢光筆）**：選取文字後可標記顏色，標記會存起來
- **我的筆記**：所有劃過的重點集中列表，可以點擊跳回原文
- **繼續閱讀**：記住上次看到哪一篇，回到首頁會有「繼續閱讀」卡片
- **字級調整、日夜模式**：跟之前一樣
- **上下篇快速切換**：在文章底部

這些記錄（閱讀進度、劃線筆記、字級、日夜模式）都存在使用者手機瀏覽器的本機儲存空間，不會上傳到任何伺服器，換手機或清瀏覽器資料會消失，這是正常現象。

## 使用說明（同前）

- **iPhone：** 開啟連結 → 分享 → 加入主畫面
- **Android：** 開啟連結 → ⋮ → 安裝應用程式
- 第一次打開請連網，之後可離線閱讀
- iOS 若太久沒開，系統可能清除快取，需重新連網一次
